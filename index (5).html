FAYVI Awards Studio ✦

Build ceremonies, create categories, shortlist nominees, score with judges, and publish frozen results.

Editorial integrity: Directory ranks, profile-wide fan votes and judged award results are different metrics. A ceremony result is published only when you explicitly approve it. Creating awards requires Firestore permissions for private awardCategories and public awardBoards.

Firebase setup — database permission for Awards Studio

In Firebase Console → Firestore Database → Rules, add the helper and the two match blocks inside your existing match /databases/{database}/documents block; retain all existing rules. Private awardCategories contain draft entries and jury scores. Public awardBoards contains only released category information. Publish and test the rules. This HTML file cannot install backend permissions.

function fayviAwardsAdmin() {
  return request.auth != null
    && request.auth.token.email == 'bonukajaniru8@gmail.com'
    && request.auth.token.email_verified == true;
}
match /awardCategories/{awardId} {
  allow read, write: if fayviAwardsAdmin();
}
match /awardBoards/{awardId} {
  allow read: if true;
  allow write: if fayviAwardsAdmin();
}
