Firebase setup — database permission for Awards Studio

In Firebase Console → Firestore Database → Rules, add the helper and the two match blocks inside your existing match /databases/{database}/documents block; retain all existing rules. Private awardCategories contain draft entries and jury scores. Public awardBoards contains only released category information. Publish and test the rules. match /awardCategories/{awardId} {

How FAYVI rankings and verification work

Fan boards use recorded votes only: one active vote per signed-in verified email account per profile, subject to database rules. Equal totals share a position. Zero votes means unranked. Votes do not measure national fame or prevent someone creating multiple accounts.

Profile completeness describes how much information is present, not whether it is accurate. A verified badge means an ownership claim was approved, not that every fact was checked. Editorial awards remain separate and disclose their method.
